# Netflix-Data-Cleaning-Task1
End-to-end data cleaning and standardization of the Netflix titles dataset.

Summary
I transformed the raw Netflix dataset into a standardized format. My process ensures that missing values don't interfere with data visualizations and that all text is consistent.

Technical Steps
Standardization: I used TRIM and PROPER to clean the Title column.

Missing Data: I filled blanks in Director and Cast with "Unknown" to maintain row count integrity.

Formatting: Converted date_added to YYYY-MM-DD for ISO compliance.

Documentation: I maintained a Data_Quality_Notes column to track all changes.
